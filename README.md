CourtCheck

Project status

CourtCheck is a small web app for my Intelligent Interactive Systems assignment. It looks at how different explanations affect people's decisions when they get a sports venue recommendation. This follows on from my Assignment 1 literature review.

The app has six fictional scenarios, three explanation types, an option to check requirements, accept and reject buttons, and a results page with CSV export. The recommendations are simulated rather than generated by a live AI model. Full participant testing has not been completed yet.

Technology stack

- HTML for the structure of the website.
- CSS for the layout, colours and design.
- JavaScript for the scenarios, decisions, requirement checks and results.
- Visual Studio Code for local development.
- GitHub Pages for hosting.
- ChatGPT for development assistance.

No database, external API, API key or additional libraries are needed.

How to run

Open the [live website](https://alpsozu.github.io/courtcheck/) or download `index.html` and open it in a browser. Select a session order and press Start session, or use the quick demo. The source code can be inspected directly in `index.html`.
